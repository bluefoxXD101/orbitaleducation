Quick Info

This project can run with localStorage fallback if the API is not available. Use it to prototype flows before connecting a backend. The optional backend included stores data in a local JSON file.

Sign-up Flow

  1. Dashboard → "Login or Sign up?"
  2. Signup: choose Parent or District/School
  3. Parent: Email, Password, Child Email/PIN, District Code
  4. District: Name, Work Email, Password, District/School Name, TOS, Plan
